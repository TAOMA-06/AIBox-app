# 智盒AI 隐私政策

请在使用智盒AI前阅读本政策。智盒AI采用 BYOK 模式：你自行选择供应商并填写自己的 API Key，应用不提供账户系统或自建 AI 后端。

## 我们不收集什么

我们不收集账户资料、API Key、输入文本、生成结果、设备标识或广告分析数据。应用没有分析 SDK、广告 SDK，也不会把本地会话上传到智盒AI服务器。

## 数据流向

用户主动提交的文本、语音转写内容和其他请求，仅发送到用户选择并配置的第三方 AI 供应商接口。预设供应商为 DeepSeek、通义千问、Kimi、智谱、OpenAI、Anthropic、Google Gemini，也支持自定义 OpenAI-compatible 地址。请分别阅读 DeepSeek（https://www.deepseek.com/policies）、通义千问（https://terms.alibabagroup.com）、Kimi（https://www.moonshot.cn）、智谱（https://open.bigmodel.cn）、OpenAI（https://openai.com/policies/privacy-policy/）、Anthropic（https://www.anthropic.com/legal/privacy）及 Google Gemini（https://policies.google.com/privacy）及自定义服务的隐私政策。

## 本地存储

API Key 保存在设备 Keychain，会话和保存的结果保存在设备 SwiftData，部分设置会镜像到本机共享偏好以支持分享扩展、快捷指令和小组件。数据不上传至智盒AI服务器，用户可在设置和历史页删除本地数据。

## 系统入口

分享扩展和快捷指令只在用户主动调用时读取内容并请求当前供应商。小组件仅显示设备本地的最近结果。

## 内购和生成内容

智盒AI Pro 由 Apple StoreKit 处理购买和恢复购买，我们不获取支付信息。内容由第三方 AI 生成，仅供参考，用户应自行核验。
