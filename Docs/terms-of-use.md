# 智盒AI 用户协议

## BYOK 与供应商

用户负责获取、保管和使用自己的 API Key，并承担第三方供应商产生的费用、速率限制和账户风险。用户必须遵守所选供应商（预设含 DeepSeek、通义千问、Kimi、智谱、OpenAI、Anthropic、Google Gemini）及自定义接口的服务条款、内容政策和适用法律。

## 生成内容

内容由第三方 AI 生成，仅供参考。用户应自行核验事实、版权、隐私和安全风险，不应将结果直接作为医疗、法律、金融或其他专业建议。

## Pro 买断

智盒AI Pro 是一次性非消耗型数字权益，由 Apple 处理购买和恢复。Pro 不包含任何第三方模型的 API 额度、供应商费用或第三方服务所有权。

## 免责与终止

在法律允许范围内，因第三方供应商、网络、模型输出、用户输入或 Key 使用导致的损失由用户自行承担。用户可随时停止使用和删除应用；违反本协议或第三方规则时应停止相关使用。
